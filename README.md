# AI 배너 생성기

Streamlit 기반으로 동작하는 배너 생성 도구입니다.  
무료 이미지 생성 엔진(Pollinations)으로 배경 이미지를 만들고, Pillow(PIL)로 문구를 합성해 최종 PNG를 생성합니다.

## 주요 기능

- **배너 생성 폼**: 배너 주제, 원하는 문구, 문구 위치(중앙/하단), 배너 사이즈 선택
- **프롬프트 자동 생성**: 주제 + 문구 + 배너 비율에 맞춰 광고용 배경 프롬프트 자동 구성
- **무료 이미지 생성**: API 키 없이 URL 기반으로 이미지 생성 요청
- **텍스트 합성(PIL)**:
  - 중앙/하단 배치
  - 이미지 폭에 맞춘 자동 폰트 크기 조절
  - 자동 줄바꿈
  - 반투명 검은색 배경 박스 + 그림자 효과로 가독성 강화
- **결과 제공**:
  - 생성된 원본 이미지 URL 표시
  - 최종 배너 미리보기
  - PNG 다운로드 버튼 제공
  - 로컬 파일 저장 버튼 제공 (`outputs/` 폴더)

## 처리 흐름

1. 사용자 입력 수집
2. 사이즈 기반 프롬프트 톤 보정
3. 무료 이미지 엔진으로 배경 이미지 생성
4. 최종 배너 크기로 리사이즈/크롭
5. 문구 합성(박스/그림자/자동 폰트)
6. PNG 바이트 변환 후 미리보기/다운로드/저장

## 다운로드 파일명 규칙

- 형식: `{주제}_{YYYYMMDD}.png`
- 예시: `여름_세일_20260324.png`

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 파일 구성

- `app.py`: 전체 앱 코드(생성 로직 + 텍스트 합성 + UI)
- `requirements.txt`: Python 의존성
- `outputs/`: 로컬 저장된 PNG 결과물 폴더(실행 중 자동 생성)
